## SEOと広告運用
- 記事完成まで noindex および robots.txt によるクロール停止。公開時には必ず解除する。
- 記事の冒頭に「まず結論」ボックスを置かない。
- 商品写真は使用権限を確認。商品に無関係なイラストや画像を流用しない。
- 本サイトはA8.net専用。Amazonアソシエイトは使用しない。A8の提携承認・正規広告リンク確認後に広告を設置する。
- A8・バリューコマースは承認済み案件の正規リンクのみ使用。報酬額は管理画面で再確認。
- 購入者レビュー要約は10件以上の実在レビューを確認した場合のみ。良い点・悪い点を公平に記述し、件数や評価を捏造しない。
- Google検索上位10件を目標に、記事ごとに検索意図・一次情報・競合との差別化を確認。
- 正式公開時には canonical、sitemap.xml、robots.txt、Search Consoleを設定。
